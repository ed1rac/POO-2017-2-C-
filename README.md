# 💻 Programação Orientada a Objetos em C# (2017.2)

Repositório contendo projetos, exercícios práticos e códigos de exemplo desenvolvidos para a disciplina de **Programação Orientada a Objetos (POO)** utilizando **C# e .NET**, ministrada pelo **Prof. Edkallenn Lima** no semestre letivo de 2017.2.

---

## 📁 Estrutura da Solução

- 📄 `POO-2017-2.sln` — Solução completa para Visual Studio.
- 📁 `POO-2017-2/` — Projetos em modo console abordando os pilares da Orientação a Objetos:
  - Classes, Objetos e Métodos
  - Encapsulamento, Getters e Setters
  - Construtores e Sobrecarga de Métodos
  - Herança e Polimorfismo
  - Classes Abstratas e Interfaces
- 📁 `POO-C#-Visual/` — Aplicações gráficas com Windows Forms desenvolvidas em sala de aula.

---

## 🚀 Como Executar

1. Abra o arquivo `POO-2017-2.sln` no **Visual Studio** (ou no **Visual Studio Code** com o C# Dev Kit instalado).
2. Selecione o projeto desejado como *Startup Project*.
3. Pressione `F5` ou execute pelo terminal:
   ```bash
   dotnet run --project POO-2017-2
   ```
